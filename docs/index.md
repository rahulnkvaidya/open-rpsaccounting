## 📊 Features Overview

### Voucher Entry
- **F3** - Receipt (Money In)
- **F4** - Contra (Cash/Bank Transfer)
- **F5** - Payment (Money Out)
- **F6** - Journal (Adjustments)
- **F8** - Sales/Billing
- **F9** - Purchase

### Reports (15 Total)
- Day Book, Ledger Report
- Sales Report, Purchase Report
- Receivables (Debtors), Payables (Creditors)
- Trial Balance, Balance Sheet, Profit & Loss
- Cash Flow Statement, GST Summary
- And more...

### Modern Features
✅ Auto-focus on new rows  
✅ Keyboard navigation  
✅ Save & Print (Ctrl+P)  
✅ Dark mode support  
✅ Real-time calculators

## 📝 Quick Reference

### Common Tasks
| Task | How To |
|------|--------|
| Cash Receipt | F3 → Enter amount → Select Cash & Sales → Ctrl+S |
| Bank Payment | F5 → Enter amount → Select Expense & Bank → Ctrl+S |
| Sales Invoice | F8 → Select customer → Add items → Ctrl+P |
| Purchase Order | PO Menu → Create → Add items → Ctrl+P |
| View Debtors | Reports → Receivables (Debtors) |
| View Creditors | Reports → Payables (Creditors) |

### Keyboard Shortcuts
| Key | Action |
|-----|--------|
| **F3-F9** | Voucher types |
| **Ctrl+S** | Save |
| **Ctrl+P** | Save & Print |
| **Ctrl+Plus** | Add row |
| **Escape** | Go back |
